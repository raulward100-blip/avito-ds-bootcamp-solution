# Решение задачи — Data Science Bootcamp от Авито

## Какие данные и признаки я использовал и почему

**Данные:**
- `train.parquet` — примеры: запрос + выбранное объявление
- `benchmark_queries.parquet` — 2 452 запроса
- `benchmark_items.parquet` — 189 212 объявлений

**Из запроса:**
- `search_query` — текст запроса, основа поиска
- `search_infm_params_text` — фильтры поиска, для точности
- `search_category` — категория, для фильтрации
- `search_location_id` — локация, для фильтрации

**Из объявления:**
- `item_title_raw` — заголовок, ключевые слова
- `item_description_raw` — описание, больше сигналов
- `item_infm_params_text` — параметры, дополнительные слова
- `item_category_id` — категория, для фильтрации
- `item_location_id` — локация, для фильтрации

**Почему:** текст — основа для сравнения, а категория и локация отсекают заведомо неподходящие объявления.

## Какие модели или алгоритмы я применил

**BM25 (Best Matching 25)** — алгоритм информационного поиска:
- учитывает частоту слова в объявлении (TF)
- учитывает редкость слова среди всех объявлений (IDF)
- учитывает длину объявления

**Фильтрация:**
- по категории: только объявления из той же категории
- по локации: только объявления из той же локации

Фильтры применяются к топ-200 кандидатам от BM25.

**Почему не нейросети:** модель эмбеддингов весит 471 МБ и требует времени. В условиях ограниченного времени и двух попыток я выбрал проверенный BM25.

## Как я проверял качество решения

| Метод | Recall@50 |
|-------|-----------|
| TF-IDF | 0.162 |
| BM25 | 0.285 |
| BM25 + фильтры | **0.412** |

Также проверял формат: только две колонки, `query_id` — 16 символов, `item_id` через пробел.

## Какие типы ошибок нашёл и что с ними сделал

**Ошибка 1: Медленная работа.**
BM25 создавался заново для каждого запроса. Решение: построил индекс один раз до цикла.

**Ошибка 2: TF-IDF давал 0.162.**
Плохо работает с короткими запросами. Решение: заменил на BM25.

**Ошибка 3: Много нерелевантных объявлений.**
Поиск по всем 189 212 объявлениям. Решение: добавил фильтры по категории и локации.

**Ошибка 4: Неправильный формат CSV.**
Лишние колонки и индекс. Решение: оставил только `query_id` и `answer`, `index=False`.

## Как воспроизвести

1. Установить зависимости:
pip install pandas numpy rank_bm25

2. Скачать данные по ссылке из условия задачи

3. Распаковать архив и положить файлы `train.parquet`, `benchmark_queries.parquet`, `benchmark_items.parquet` в ту же папку, где лежит `solution.py`.

4. Запустить:
python solution.py

5. Получить файл `answer.csv` в той же папке.
